Getting a free YouTube Data API key

Pass 1 (creator self-disclosure) checks video status through YouTube's own Data API, which requires a free API key tied to a Google Cloud project. The key never leaves your browser — it's stored in chrome.storage.local and used only to call googleapis.com directly from the extension.

Or, step by step

  1. Create a project and enable the API

    Google's setup flow creates a Google Cloud project and turns on the YouTube Data API v3 for it in one click — no manual configuration needed.

    Open the API setup wizard →

    Choose "Create a new project" if asked. Any project name is fine — it's just a container Google uses to track your API usage and quota.

  2. Create an API key

    In the Credentials page, click + Create Credentials at the top, then choose API key from the dropdown. Google generates one instantly — no form to fill in.

    Open Credentials →

  3. Copy it into the extension

    Click the copy icon next to the new key, then paste it into the API key field in the extension's popup and click Save. That's it — Pass 1 starts working on the next check.

No credit card is required for this. The YouTube Data API's free quota (10,000 units/day — a batched status check costs about 1 unit regardless of how many videos are in it) is far more than normal browsing uses. Google may still prompt you to "enable billing" on the project as a formality for some accounts; you can decline or skip it and the key keeps working within the free quota.

Questions

Why doesn't the extension just get the key for me?

Doing that automatically would mean asking you to sign in to Google through the extension and grant it broad Cloud Platform permissions — enough to create projects and provision credentials on your account. That's a much bigger ask than a filter extension should need, and it's the kind of permission that's genuinely worth being cautious about. Copy-pasting one key takes under a minute and keeps the extension's access to exactly one thing: reading public video status.

Is this safe to leave without a key?

Yes. Without a key, Pass 1 (self-disclosure) just stays off — the extension still runs Pass 2 (the watch-page auto-detect scan) if it's enabled, and the popup shows a status banner when a key is missing so you know it's off, not silently broken.

What if I hit the daily quota?

The extension backs off automatically and shows the reset time in the popup. Pass 2 keeps working in the meantime, since it doesn't use this API key at all.

Can I revoke or rotate the key later?

Yes — delete or regenerate it any time from the same Credentials page, then paste the new one into the popup. The old one stops working immediately.
